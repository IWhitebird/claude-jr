A coding agent in one 3 MB binary.

claude-jr is a small, fast alternative to Claude Code, written in Rust. It reads and edits your code and runs commands, asking before anything changes, on 2 MB of memory when idle.

$curl -fsSL https://claudejr.iwhitebird.com/install | sh

Linux and macOS, x86 and ARM; Windows through WSL. Then run claudejr.

Subagents

Hand side tasks to agents that work in parallel and report back.

Five permission modes

From asking about everything to an auto mode where a small model reviews each command.

▣

A real sandbox

On Linux it runs inside bubblewrap: it can only write to your project, and your keys stay hidden.

↶

Rewind and resume

Go back to before any message, file changes undone. Every session is saved as it goes.
