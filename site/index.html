A coding agent for the terminal, in a 1.8 MB binary.

claude-jr, or Claude Junior, is a small alternative to Claude Code: it reads your code, edits files and runs commands, asking before anything changes. It is written in Rust with no runtime, so it starts in 5 ms and sits in 0.7 MB of memory: 180 times less disk and 190 times less memory than Claude Code.

curl -fsSL https://claudejr.iwhitebird.com/install | sh

Linux and macOS, on x86 and ARM; on Windows, inside WSL. Then run claudejr and paste an Anthropic API key.

Small enough not to notice

There is no Node or Python to install and nothing running in the background. Memory stays under 4 MB however long a session runs, because the conversation is kept on disk. A whole working session, including the commands it runs, fits in a 16 MB container on a twentieth of a CPU core.

What's in it

Subagents
Side tasks go to agents that work in parallel and report back.
Permission modes
From asking about everything to an auto mode where a small model reviews each command. shift tab switches.
A sandbox
With --sandbox on Linux it can only write to your project; keys, sockets and the rest of your home stay out of reach.
Rewind and resume
Go back to before any message with its file changes undone. Every session is saved as it goes.
Skills and MCP
Reads your .claude/skills and talks to MCP servers, local or remote.
Images and the web
Drag in a screenshot, and it can search and fetch pages when the task needs them.
A stash
ctrl s puts a half-written message aside while you send another.
Scripting
claudejr -p "…" runs one prompt, with JSON output and a spending limit for CI.
