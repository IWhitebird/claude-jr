## claude-jr 0.3.0

### New

- **Windows.** A native build: `irm https://claudejr.iwhitebird.com/install.ps1 | iex` in PowerShell. Commands run in Git Bash when Git for Windows is installed, otherwise in PowerShell. This is its first release: it is built and tested on a Windows machine in CI, but the interactive UI has had little use there yet, so please report what you find. No sandbox on Windows. [Guide](https://claudejr.iwhitebird.com/guide#windows)
- **Claude through Amazon Bedrock and Google Vertex AI**: `-m bedrock/claude-opus-5-5`, `-m vertex/claude-opus-5-5`. Built from the documentation and checked against a stand-in; **not yet tested against the real services**. If you have an account, `bench/provider.sh bedrock/claude-haiku-5-5` is the test. [Guide](https://claudejr.iwhitebird.com/guide#claude-through-amazon-bedrock-or-google-vertex-ai)
- **A worker model.** Background tasks, fleets, tasks started over MCP and subagents now run on `claude-haiku-5-5` unless you say otherwise (`"worker_model"` in the config, `CLAUDE_JR_WORKER_MODEL`, or `-m`). The model each task used is shown in `task list` and its result. **This changes behaviour:** subagents of an Opus session used to run on Opus.
- **A Docker image, 3.5 MB:** `docker run --rm -it -e ANTHROPIC_API_KEY -v "$PWD:/work" ghcr.io/iwhitebird/claude-jr`, for x86-64 and ARM. It is the binary on busybox; to use it with your own tools, `COPY --from=ghcr.io/iwhitebird/claude-jr /usr/local/bin/claudejr /usr/local/bin/`. [Guide](https://claudejr.iwhitebird.com/guide#docker)
- **Homebrew and Cargo.** `brew tap iwhitebird/claude-jr https://github.com/IWhitebird/claude-jr && brew install claude-jr`, or `cargo binstall --git https://github.com/IWhitebird/claude-jr claude-jr`.
- **No bash needed.** On a system with only `sh` (Alpine, busybox) commands run in that, and the model is told so.

### Measured

- **SWE-bench Verified, all 500 tasks: 467 resolved (93.4%)** with Claude Opus 5.5, one attempt each, $67.32.
- Next to Claude Code 2.1.326 on the same machine: 177 times less disk, 200 times less memory idle, 130 times less at its peak, and a fifth of the instructions and tool definitions sent with each request.
- Handing ten pieces of work to subagents or workers was slower and cost more than one agent doing them, at both sizes tried. [Benchmarks](https://claudejr.iwhitebird.com/benchmarks) has this and every other number.

### Fixed

- `task start -m ollama/...` no longer asks for an Anthropic key.
- A task's file list includes files the agent committed itself.
- The fake API used for tests accepts a system message partway through a conversation.

### Inside

- The source is reorganised into folders by what the code does (`cli`, `ui`, `agent`, `tools`, `api`, `work`, `store`, `sys`), no file over about 500 lines. [Architecture](https://claudejr.iwhitebird.com/architecture)
- 402 tests; the failure matrix runs through Anthropic's API, Chat Completions, Bedrock and Vertex.

**Updating:** `claudejr --update`, or run the install line again.
