## claude-jr 0.3.1

Fixes only. All of them were found by throwing damaged input at the program on purpose; none was reported by a user.

### Fixed

- **A malformed reply from a model server could crash it.** A content block that was no object, or a stream chunk missing a field, aborted the program. Such a reply is now an error (retried if nothing had arrived yet). In the Chat Completions format, a chunk numbering a tool call in the millions made it ask for 4.8 GB of memory.
- **A blank text block from the model broke the conversation.** Models now and then send a text block with nothing in it; it was kept, and the API refuses a conversation that has one, so every later request of that session failed. They are left out, also from session files written by earlier versions.
- **One stray line from an MCP server left every later call to it waiting ten minutes.** A line that wasn't UTF-8 stopped claude-jr listening to a server that was still running. Replies sent inside a list are understood, and calls to a server that has gone fail at once.
- **An edit could blow a file up.** "Replace every newline with this page of text" was carried out, gigabytes of it, in memory and then on disk. An edit whose result would pass 64 MB is refused.
- **A damaged session file could never be continued.** If a line went missing from the middle of the file, what was left broke the API's rules and every request was refused. What no longer fits is left out on loading, and you are told.
- A tool call that arrives twice is run once; a tool call with a blank prompt for a subagent is refused instead of starting one.

### Inside

- Five checks that play damaged input at the real program: hostile tool calls and damaged reply streams (`bench/toolfuzz.py`), a misbehaving MCP server (`bench/mcpfuzz.py`), damaged settings files (`bench/startfuzz.py`) and damaged session files (`bench/damage.py`). The random-keys run types wide, combining and right-to-left text.
- 423 tests.

**Updating:** `claudejr --update`, `brew upgrade claude-jr`, or run the install line again.
