claude-jr Claude Junior

A coding agent for the terminal in one 3 MB binary. claude-jr is a small, fast alternative to Claude Code, written in Rust: it talks to Claude, reads and edits your files, and runs commands, asking before anything changes.

3.2 MBbinary, no runtime

5 msto start

Install

curl -fsSL https://raw.githubusercontent.com/IWhitebird/claude-jr/main/install.sh | sh

Linux and macOS, x86_64 and ARM. On Windows, run it inside WSL. Then run claudejr; it asks for your Anthropic API key the first time. claudejr --update gets the newest release.

Why

  • Tiny. One static 3.2 MB file. No Node, no Python, nothing to install first.
  • Light. 2 MB of memory when idle and 5 to 6 MB in a long session. A whole session fits in a 16 MB container on a twentieth of a CPU core.
  • Fast. It starts in 5 ms and uses no CPU while it waits.
  • Complete. Subagents, skills, MCP, images, web search, rewind, a sandbox and five permission modes.
  • Tested. 285 tests with 98% line coverage.

Use

claudejr                        # start in this folder
claudejr -c                     # continue the last conversation
claudejr -p "explain main.rs"   # one prompt, print the answer
claudejr --sandbox              # only allow writes inside this folder
